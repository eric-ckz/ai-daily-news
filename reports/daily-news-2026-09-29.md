The platform also includes a separate security layer called Sentry that runs onboard a chip to constantly monitor AI agent activity and can “intervene instantly” if the agent starts trying to move beyond its target, the company said. “OpenShell governs the agent’s actions, and then Sentry independently monitors and contains suspicious behavior,” Boitano said.    - 摘要：[Skip to content](#main-content) [News](/) English #LLMs # Seven ESP32-S3 boards form a distributed 1.58-bit LLM cluster • ![Elena Varga](/_next/image?url=%2Fauthors%2Felena-varga.webp&w=64&q=75) [Elena Varga](/author/elena-varga) •4 min read Share this article An open-source project links seven ESP32-S3 boards into a pipeline for running a heavily compressed language model. The design splits tokenization, transformer layers and sampling across the cluster through a dual-channel SPI daisy chain. A cluster of seven ESP32-S3 boards can run a quantized language model by dividing inference across separate microcontrollers. The [ESP32s3-LLM-Cluster project on GitHub](https://github.com/Low-Zi-Hong/ESP32s3-LLM-Cluster) assigns one board to orchestration and six boards to transformer computation. The repository title describes a 0.4B model, while its architecture notes describe a sliced 0.5B model. That mismatch leaves the exact model size unclear, but the system design remains specific: the boards use 1.58-bit ternary weights, custom ESP-IDF firmware and high-speed SPI links to pass the model state from one board to the next. ## One prompt, seven boards The master board accepts a prompt, runs the BPE tokenizer and looks up token embeddings. The embedding data uses INT4 storage and occupies about 14 MB of flash. The master then sends each hidden-state vector to the first compute board through one SPI channel. Each compute board handles four transformer blocks. The first node processes layers 0 through 3. The next nodes continue the sequence until the sixth compute board finishes layers 20 through 23. Every node runs RMSNorm, attention, rotary positional embeddings, a key-value cache and the model's multilayer perceptron layers. The final compute node sends its result back to the master through the return side of the SPI chain. The master applies the final RMSNorm, runs the language-model head and selects the next token with greedy sampling. The project stores the final normalization data in a 64 KB `fnorm` partition and ties the language-model head to the INT4 embedding table. The topology turns seven small boards into one inference pipeline.
